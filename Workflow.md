# Как работать над проектом

## Окружение

Для удобства работы над проектом используются инструменты из **Node.js** и **npm**. Убедитесь, что на рабочем компьютере установлен актуальный LTS релиз **Node.js**. Актуальная версия указана в файле `package.json` в поле `engines.node`. Затем, в терминале, перейдите в директорию с проектом и _единожды_ запустите команду:

```bash
npm install
```

Команда установит зависимости проекта.

## Переменные окружения

Настройки сервиса передаются через переменные окружения. Список всех переменных:

PORT=4000 — порт REST-сервера.
HOST=localhost — хост, на котором запускается сервис (используется для абсолютных URL статики).
DB_HOST=127.0.0.1 — адрес сервера MongoDB.
DB_USER= — имя пользователя MongoDB (пустое значение для локальной БД без авторизации).
DB_PASSWORD= — пароль MongoDB (пустое значение для локальной БД без авторизации).
DB_PORT=27017 — порт MongoDB.
DB_NAME=six-cities — имя базы данных.
SALT=secretSalt — соль для хеширования пароля.
UPLOAD_DIRECTORY=./upload — каталог для загруженных файлов.
JWT_SECRET=secretKey — секрет для подписи JWT.
STATIC_DIRECTORY_PATH=static — каталог со статическими файлами по умолчанию.

Для удобства используется файл `.env`. Он не хранится в системе контроля версий. Пример значений лежит в `.env-example`.

## Запуск проекта

1. Установите Node.js версии, указанной в `package.json`.
2. Установите и запустите MongoDB локально (по умолчанию `127.0.0.1:27017`).
3. Скопируйте `.env-example` в `.env` и при необходимости измените значения.
4. Выполните `npm install`.
5. Для разработки REST-сервера: `npm run start:dev`.
6. Для запуска собранного сервера: `npm start`.
7. CLI: `npm run cli -- --help`.

Если какая-то обязательная переменная окружения не задана, сервис выведет ошибку и завершит работу.

## Сценарии

Все сценарии описаны в `package.json`.

start — собирает проект и запускает REST-сервер из `dist`.
start:dev — запускает REST-сервер в режиме разработки с перезапуском при изменениях.
build — очищает `dist` и компилирует TypeScript.
compile — компилирует TypeScript в `dist`.
clean — удаляет директорию `dist`.
lint — проверяет исходники ESLint.
lint:fix — автоматически исправляет замечания ESLint.
ts — выполняет TypeScript-модуль через `ts-node` без предварительной сборки.
mock:server — поднимает json-server с моковыми данными.
cli — запускает CLI-интерфейс приложения.

## Структура проекта

### Файл `Readme.md`

Инструкции по работе с учебным репозиторием.

Советы и инструкции по внесению изменений в учебный репозиторий.

### Остальное

Все остальные файлы в проекте являются служебными. Пожалуйста, не удаляйте и не изменяйте их самовольно. Только если того требует задание или наставник.
